# Navigation

Dwains Dashboard Next has separate navigation behavior for desktop and mobile.

## Desktop

Desktop uses:

- Home
- Devices
- More pages
- Area sidebar

The area sidebar can be resized or collapsed. When it is collapsed, areas are shown on the home page so the dashboard can be used in a more classic Dwains Dashboard layout.

Each area shows status badges: lights on (tap the badge to turn them off), switches, covers, climate, media, fans, unlocked locks and motion, then one badge per alert type such as open windows, open doors, leaks and smoke. Urgent badges are red and come first, see [Status cards](home-page.md#status-cards). When not all badges fit, a **+N** badge shows how many are left out; a wider sidebar fits more, up to eight. The area cards on mobile show up to four badges.

## Mobile

Mobile uses a bottom navigation bar:

- Home
- Devices
- More pages

The standalone menu button opens the Home Assistant sidebar. Inside an area it becomes a back button to Home, and inside a device group it becomes a back button to the devices overview.

## Area Switching

On mobile, the Home tab can open an area selector from the bottom. On desktop, areas are normally selected from the left area sidebar.

## Device Switching

On mobile, the Devices tab opens the devices overview first. From there you can open a specific device group such as lights, covers, people, maintenance or energy.
